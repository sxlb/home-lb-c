# 链接管理界面改造（S1）设计文档

- 日期：2026-08-29
- 状态：已批准
- 涉及模块：后台链接管理面板（社交链接 / 网站链接共用）
- 关联计划：后台增强批次一（S1 + S2 + S7）

## 背景与目标

后台「社交链接」「网站链接」共用 `LinksPanel` 组件。当前每行卡片存在四个体验问题：

1. 左侧 40px"拖拽手柄 + 序号"栏是伪装的（无实际拖拽，排序靠数字输入），浪费空间且误导用户
2. 每行卡片内嵌完整表单 + 图标选择器（两个 Tab + 图标网格），单行最高 300px+，多条链接时页面冗长
3. 图标选择器行内展开，视觉拥挤
4. 删除按钮绝对定位与表单区域重叠风险；保存按钮无"未保存变更"状态提示

目标：改造为**折叠式列表 + 行内编辑**，列表即前台预览形态，编辑按需展开，交互清晰。

## 设计决策

### 1. 列表项（收起态）

每行收为紧凑预览行：`[图标缩略图] 名称 + URL（灰字截断） | 排序上移/下移 | 编辑 | 删除`

- 图标缩略图：40px 圆角方块，实时解析图标（`lucide:xxx` 用 lucide 组件；iconfont symbol 用 `<svg><use href="#icon-xxx">`；兜底 Globe）
- 删除按钮 hover 显示（移动端常显）
- 去掉伪拖拽手柄栏与行内序号

### 2. 编辑态（展开）

点击行展开编辑区，同一时间只展开一行（展开新行自动收起旧行）。

- 表单字段保留：名称、图标（输入框 + Lucide/图标库 Tab 选择器）、链接地址、悬停提示（社交链接独有）、排序
- 底部"完成"按钮收起；未展开时图标选择器零渲染

### 3. 状态与交互

- 未保存提示：增删改后保存按钮变"● 有未保存的更改"高亮态，保存成功恢复
- 排序：上移/下移按钮直接调换相邻行 sort（本地重排，保存时统一提交）
- 空状态保留现有引导
- 响应式：移动端操作按钮常显、列表单列

### 4. 技术方案

- 改造 `components/admin/LinksPanel.tsx`：新增内部 `LinkRow` 组件（收起/展开状态）+ 图标预览逻辑
- 复用：`useLinkList`、`IconPickerTabs`（展开时渲染）、`lucideIconResolver`
- 新增：图标预览组件（Lucide 解析 + iconfont symbol + 兜底）
- 不改后端 API 与数据结构

### 5. 文件变更

- Modify: `components/admin/LinksPanel.tsx`（主面板 + LinkRow + 图标预览）
- 不改：`useLinkList.ts`、`IconfontPicker.tsx`、`LucideIconPicker.tsx`、后端路由

### 6. 测试与验收

- 现有测试全过（links-schema / diff-links 等不受影响）
- 手工清单：社交、网站两个面板；展开/收起、排序移动、删除、保存提示；移动端布局

## 非目标

- 真实拖拽排序（本方案用箭头按钮，避免引入 dnd 库）
- 后端排序批量接口改造（沿用 useLinkList 现有保存逻辑）
